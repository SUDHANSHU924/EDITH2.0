                        QUICK START
================================================================================

1. Using Main Model (DeepSeek V4):
   ---
   from agents.model_router import router
   
   response = router.call_deepseek_v4_pro(
       messages=[{"role": "user", "content": "Your query"}],
       thinking=True
   )

2. Using Mistral (Documents):
   ---
   response = router.call_mistral_requests(
       messages=[{"role": "user", "content": "Generate report"}],
       temperature=0.15,
       stream=True
   )

3. Using Vision (Images):
   ---
   response = router.call_vision_requests(
       messages=[{
           "role": "user",
           "content": [
               {"type": "text", "text": "Analyze image"},
               {"type": "image_url", "image_url": {"url": "data:..."}}
           ]
       }]
   )

4. Using DeepSeek R1 (Security):
   ---
   response = router.call_deepseek_r1(
       messages=[{"role": "user", "content": "Security threat?"}],
       max_tokens=4096
   )

================================================================================
                        FALLBACK STRATEGY
================================================================================

If NVIDIA API fails:
   Primary   → NVIDIA NIM APIs
   Fallback  → Groq APIs (Llama 3.3, etc.)
   
Automatic routing:
   NVIDIA unavailable?    → Try Groq
   Both available?        → Use NVIDIA (lower latency)
   Both unavailable?      → Raise exception with details
